# FinDeg — כמה נשאר לי בתואר? 🎓

כלי סטטי (ללא שרת) לבדיקת התקדמות בתואר ולתכנון סמסטרים בטכניון, בנוי סביב
מנוע השוואה/תכנון אחד המשותף לכל הפקולטות - כל פקולטה מחוברת אליו כמודול
נתונים נפרד (`faculties/<id>/`). מעלים תדפיס ציונים (PDF), הכלי מזהה אוטומטית
את **הפקולטה** ואת **המסלול** מתוך כותרת התעודה, טוען את דרישות הקטלוג
המתאימות, ומציג מה הושלם ומה נשאר — הכול **בדפדפן בלבד**, בלי לשלוח את
הציונים לשום מקום.

## מה נתמך

כרגע פקולטה אחת בנויה במלואה, ותבנית placeholder שממחישה איך מוסיפים עוד אחת:

| פקולטה | סטטוס |
|---|---|
| הנדסה אזרחית וסביבתית (`faculties/civil/`) | בנויה במלואה - כל המסלולים/התמחויות, ראו טבלה למטה |
| `faculties/_template/` | תבנית placeholder בלבד - לא פקולטה אמיתית, לא מזוהה אוטומטית מתדפיס |

מסלולי הנדסה אזרחית וסביבתית:

| מסלול | תשפ"ד | תשפ"ה | תשפ"ו |
|---|---|---|---|
| הנדסה אזרחית — ניהול ובנייה | ✓ | ✓ | ✓ |
| הנדסה אזרחית — הנדסת מבנים | ✓ | ✓ | ✓ |
| הנדסה אזרחית — התמחות מים / תחבורה | ✓ | ✓ | ✓ |
| הנדסת מיפוי וגיאו-אינפורמציה (מסלול ארבע-שנתי) | ✓ | ✓ | ✓ |
| הנדסת סביבה | ✓ | ✓ | ✓ |

יכולות עיקריות:

- זיהוי אוטומטי דו-שלבי: פקולטה (מדף הנחיתה הראשי) ואז מסלול בתוכה (מכותרת
  התעודה), וכן שנת הקטלוג (מהסמסטר המוקדם ביותר).
- מקצועות חובה עם שקילויות (חדו"א 1מ'/1מ2, פיזיקה 1ל, "חומרי בנייה"+"מבוא להנדסת חומרים" במקום "יסודות חומרי בנייה" ועוד).
- קבוצות בחירה: שרשראות ניהול ובנייה, קבוצות א'/ב' עם מינימום מקצועות ומינימום נקודות.
- בחירת הפרויקט המתוכנן (במסלול ניהול ובנייה) מוסיפה אוטומטית את מקצועות הקדם שהוא גורר.
- "סמן כהושלם" לכל דרישה (לפטורים/שקילויות שאושרו במזכירות) — נשמר ב-localStorage.
- בדיקה צולבת מול שורת "צבר X נקודות מתוך Y" שבתדפיס.
- תרשימי זרימה: מסלול מומלץ, תכנון אופטימלי אוטומטי, ותכנון ידני בגרירה.

## הרצה מקומית

הדרך הפשוטה: דאבל-קליק על `start-findeg.bat` - זה פותח שרת מקומי קטן וגם את הדפדפן
אל <http://127.0.0.1:8358> אוטומטית (דף הנחיתה הכללי). סגירת חלון השרת שנפתח עוצרת את השרת.

(הדרך הידנית, אם צריך: לפתוח `index.html` ישירות בדפדפן, או אם הדפדפן חוסם את קורא
ה-PDF בפרוטוקול `file://`, להריץ `cd C:\FinDeg` ואז `python -m http.server 8358`.)

כדי לדלג ישר לפקולטה מסוימת בלי דרך דף הנחיתה: `faculties/civil/index.html`.

## פריסה לאתר חינמי

האתר סטטי לחלוטין (HTML/CSS/JS בלבד, כולל pdf.js מקומי) ולכן עולה לכל אחסון סטטי חינמי:

- **GitHub Pages**: `git init` → דחיפה לריפו → Settings ▸ Pages ▸ Deploy from branch.
- **Netlify / Cloudflare Pages / Vercel**: גרירת התיקייה לממשק או חיבור לריפו. אין build — התיקייה היא האתר.

לפני פרסום: ודאו ש-`test-data/` (תדפיס הדוגמה — מידע אישי!) לא עולה. היא כבר ב-`.gitignore`.

## הוספת פקולטה חדשה

ראו את ההערה בראש `faculties/registry.js` ואת `faculties/_template/` לשלד
המינימלי. בקצרה:

1. מעתיקים את `faculties/_template/` לתיקייה חדשה (`faculties/<id>/`).
2. ממלאים `data.js` בדרישות התואר בפועל (ראו `faculties/civil/data.js` לדוגמה
   מלאה) - אפשר להתחיל "barebones" כמו בתבנית (רק סה"כ נק' נדרש, בלי מקצועות
   חובה ספציפיים) ולהעמיק בהדרגה.
3. אם רוצים זיהוי-מסלול אוטומטי מהתדפיס: `detect.js` (ראו `faculties/civil/detect.js`).
4. מוסיפים רשומה ל-`faculties/registry.js` עם `detect()` ברמת-הפקולטה (ביטוי
   שמופיע בכותרת התדפיס של *כל* הסטודנטים בפקולטה, לא תלוי-מסלול).

## עדכון לקטלוג חדש (למשל תשפ"ז) - הנדסה אזרחית וסביבתית

1. מוציאים מהקטלוג את טבלאות החובה, קבוצות הבחירה והפרויקטים של כל מסלול.
2. מוסיפים ב-`faculties/civil/data.js` רשומת שנה חדשה לכל מסלול (ראו `mgmtYear` / `structuresYear` / `civilYear`).
3. מוסיפים את השנה ל-`yearCatalogs` (שנה לועזית → מפתח) ול-`yearLabels`.
